# Rafsan Alam — Portfolio

My personal portfolio website: a simple, responsive single page with About, Projects, Skills and Contact sections.

## Features
- Light and dark themes with a toggle button (your choice is remembered)
- Responsive layout for phones, tablets and desktops
- Contact form that opens a pre-filled email
- Plain HTML, CSS and JavaScript — no build step or dependencies

## Run it locally
Open `index.html` in any web browser.

## Files
- `index.html` — page content
- `styles.css` — styling and themes
- `script.js` — menu, theme toggle, scroll animations and contact form
